Serial terminal to communicate with devices in the simulation.

Connect Rx and Tx Pins to Tx and Rx from a device.
Click "Open" button to open terminal.

Property: (default value)

- Show data buses: (false)
   Show optional 8-bit Tx-bus and Rx-bus outputs for a Logic Analyzer.
   Enable Bus mode on the analyzer channel before connecting it.
   Tx-bus holds the last completed transmitted byte; Rx-bus holds the
   last received byte, both from this terminal's point of view.
   Switching this option off disconnects the two bus wires.
   Consecutive identical bytes leave the bus value unchanged.

- Baudrate: (9600)
   Transmission speed.

- Data Bits: (8)
   Number of data bits.

- Stop Bits: (1)
   Number of stop bits.
